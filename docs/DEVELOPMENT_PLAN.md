# 开发计划

详细的三阶段路径见 [`THREE_STAGE_DEVELOPMENT_PLAN.md`](THREE_STAGE_DEVELOPMENT_PLAN.md)。本文件用于跟踪当前工程拆分和完成情况。

## 第一阶段：可运行基础

状态：第一阶段代码闭环已完成。已在 macOS 上实测初始化后的启动、状态、重启、停止、端口占用、自启动、备份和恢复；Windows 与 Linux 脚本已提供，需在对应系统执行最终环境验收。

- Django 5.2 LTS 项目和 SQLite 配置
- Vue 3、TypeScript、Vite 和 Element Plus 前端壳
- Windows、macOS、Linux 的初始化、启动、停止、重启、状态、日志、备份、恢复和自启动脚本
- 健康检查接口和生产式静态前端服务
- Session 用户名登录、组织树创建、组织切换和层级路径展示
- 成员新增、姓名和联系方式维护、停用、恢复、移除和角色切换
- 角色创建、按菜单分组的权限分配、编辑、删除和审计日志
- 站点 Logo、登录页欢迎语/描述和首页标题/描述配置
- 供 AI 生成业务复用的安全文件上传和 Excel 解析模块
- 统一的 Element Plus 图标样式约定，不预置额外业务模块
- DeepSeek 优先的 OpenAI-compatible 模型配置、加密 API Key、SSE 对话
- 声明式 Feature Manifest 校验、发布、停用和记录 CRUD
- 按台账、图表、表单、流程等功能形态划分的 AI 填空式模板、方案生成和用户确认创建草稿 Feature

## 第二阶段：高效创建真实业务

状态：规划中。

- 邀请、接受、重新加入和更完整的成员生命周期
- 角色复制、批量授权和数据范围策略
- Feature 关联字段、条件显示、计算字段、导入导出和批量操作
- Feature 版本、预览、回滚和差异展示
- AI 工具调用、风险分级、确认、撤销和完整审计
- 受控代码扩展的草稿、验证和启用流程

状态：规划中。
